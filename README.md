# Exploratory Data Analysis (EDA) on Iris Dataset

## Project Overview

This project demonstrates Exploratory Data Analysis (EDA) on the Iris dataset using Python. The analysis focuses on understanding the dataset, checking data quality, identifying patterns, and visualizing relationships between different features.

## Objectives

- Explore the structure of the dataset.
- Check for missing and duplicate values.
- Perform statistical analysis.
- Create visualizations to understand the data.
- Identify patterns, trends, and outliers.

## Dataset

- **Dataset:** Iris Dataset
- **Records:** 150
- **Features:** 5

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Tools and Technologies

- Python
- Visual Studio Code (VS Code)
- Pandas
- Matplotlib
- Seaborn

## Project Steps

1. Loaded the Iris dataset.
2. Explored the dataset structure.
3. Checked data quality.
4. Performed statistical analysis.
5. Created visualizations.
6. Identified patterns and trends.
7. Documented observations and conclusion.

## Visualizations

- Histogram
- Box Plot
- Scatter Plot
- Heatmap
- Bar Graph

## Key Findings

- The dataset contains 150 records and 5 columns.
- No missing values were found.
- No duplicate records were found.
- Petal length and petal width show a strong positive correlation.
- The dataset is clean and suitable for machine learning.

## Conclusion

Exploratory Data Analysis was successfully performed on the Iris dataset. The analysis provided valuable insights into the dataset through statistical summaries and visualizations. The dataset is clean, balanced, and suitable for further machine learning tasks.
